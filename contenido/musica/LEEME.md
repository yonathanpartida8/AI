# 🎵 Tu música

Pon aquí tus MP3 (musica1.mp3, musica2.mp3, musica3.mp3…).

Después edita **src/config/musicLibrary.js** — la zona marcada con
★★★ CAMBIA AQUÍ TU MÚSICA ★★★ — para ponerles título y artista.

Por defecto la biblioteca apunta a ESTA carpeta (./contenido/musica/),
así que al subir el proyecto a GitHub Pages tus canciones funcionan
directamente. También puedes apuntar a otro repositorio remoto.
